# dg.o Collaboration Atlas

Interactive map and tables of co-authorship and topics across 812 papers presented at the International Conference on Digital Government Research (dg.o), 2000 to 2024.

Live page: https://cred1747.github.io/dgo-atlas-/

Built for the editorial "25 years of Digital Government Research" (Government Information Quarterly). Data: DGRL v2.1 dg.o corpus; author affiliations from OpenAlex, Crossref, ROR and manual lookups (ACM Digital Library and the papers); topics from a k=10 BERTopic model.

The page is a single self-contained file (`index.html`); it loads D3 from a CDN.
